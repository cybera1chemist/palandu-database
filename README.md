## 具体交互

### 提供ip阶段

最开始玩家第一次打开的时候，控制台上会显示一段文字（中文的），大意为：（允许ai适当改下下面这段文字，以使其看起来更专业、更像黑客一点）
要运行破解程序，仍需要数据库服务器的ip地址，请允许以下代码以提供ip地址：
run cute_rabbit.exe -ip {put_the_ip_here}

ip 的正确答案：暂时还没想好，暂时用123.456.789好了，之后再改

玩家可以输入文字并按回车键发送，如果：
- 格式不对，则提示玩家说查询不到该指令之类的话；
- 格式对了，但是ip不对，则提示玩家说破解失败，可能是因为ip错误
- 全对，则提示破解成果，并跳转到查询数据库阶段
