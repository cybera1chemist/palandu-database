## 项目介绍

这是一个网页解密游戏的一部分，并不是一个真实要用的数据库网站。

它的外观看起来不像是一个普通的网页，而是像是一个黑客用的控制台，黑底绿字的那种。

上方是控制台的输出，而玩家输入的地方则固定在最下面一行。

#### 错误处理

未知命令（例如：输入了 start、hello 等不支持的命令）
[ERROR] 未知指令。无法识别当前操作，请使用指定的启动命令。使用help命令以查看指引。

程序名称错误（玩家输入了run+错误的程序名）
[ERROR] {玩家输入的程序名}不是有效的可执行程序。使用help命令以查看指引。

参数格式错误（输入了 run cute_rabbit.exe，后面的-E -N没写对）
[ERROR] cute_rabbit.exe 参数无效，无法运行。使用help命令以查看指引。

小数点精度错误
[ERROR] cute_rabbit.exe 参数数值精度有误，无法运行。使用help命令以查看指引。
